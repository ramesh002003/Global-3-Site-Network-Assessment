## Executive summary prompts

- What was assessed?
- Which locations and technologies were in scope?
- What is working as expected?
- What are the most significant verified risks?
- What actions are recommended first?
- What could not be verified, and why?

## Finding format

**Finding ID:** F-001  
**Site:** HQ / Branch 1 / Branch 2  
**Domain:** WAN / Switching / Routing / Security / Wireless / Operations  
**Observation:** State the verified condition.  
**Evidence:** Evidence ID or approved report reference.  
**Business impact:** Explain potential operational impact.  
**Risk:** Critical / High / Medium / Low.  
**Recommendation:** State the corrective action.  
**Priority / owner / target:** To be agreed with the client.
